# 06 — מה נבדק

מסגרת: `pytest`. הרצה: `python -m pytest tests -q`.

## מה נבדק בכל פעולה

השמות תואמים לאפיון הפונקציונלי.

| יחידה | בדיקה |
|---|---|
| כניסה והרשאה | הרשמה יוצרת משתמש; התחברות נכשלת בסיסמה שגויה; מועמד לא נכנס ללוח הבקרה; דלת המגייסים מחייבת תפקיד, דלת המועמדים מתעלמת מתפקיד מזויף, וכל דלת עוצרת את הסוג השני; כניסת Google נבדקת בלי גוגל אמיתי: נרשם שהכניסה מגוגל, התפקיד נלקח מהדלת, חשבון קיים נכנס, ואימייל לא מאומת נדחה (`tests/test_doors_google.py`) |
| מחזור חיי משרה | המגייסת יוצרת טיוטה; רק מנהל הגיוס פותח וסוגר; הוא רואה טיוטה ממתינה ברשימה ובלוח; הוא לא כותב משרה ולא מחליט על מועמד (`tests/test_jobs.py`) |
| איתור משרות | חיפוש מחזיר משרה פתוחה לפי מילה; הרשימה היא כרטיסים עם דפדוף וספירה (`tests/test_jobs.py`) |
| הגשת מועמדות | הגשה נשמרת ומעלה את מספר הנרשמים למשרה |
| לוח בקרה | הלוח סופר משרות פתוחות ונרשמים; הטבלה מדפדפת והסיכום נשאר על כל המשרות (`tests/test_apply_dashboard.py`) |
| התאמה סמנטית | שני קורות חיים שונים מקבלים דירוג לפי דמיון |
| הערכת סוכן | תהליך הרקע על מועמדות שהוגשה שומר ציון |
| החלטת גיוס | דחייה משנה סטטוס ונשמרת; הדף לא שולח מייל; תהליך הרקע שולח פעם אחת ורושם שהמייל נשלח; כישלון נרשם ונעצר אחרי 3 ניסיונות; בלי חיבור ל־Gmail לא נשלח ולא נרשם כלום (`tests/test_decision_email.py`) |
| דירוג מועמדים | מי שדורג מסודר לפי ציון, ומי שלא דורג אחריהם לפי דמיון; יש סיכום המלצות; מועמד לא נכנס לדף |
| הערכה חוזרת | הבקשה נשמרת, המועמדות חוזרת לתור, וההיסטוריה מציגה שני ציונים וההפרש; מועמד לא יכול לבקש; אחרי 3 כישלונות הבקשה פותחת ניסיונות חדשים |
| תתי-סוכנים | בבדיקה בלי מודל אמיתי רואים את המנהל, אחר כך את עוזר קורות החיים, אחר כך את עוזר הרשת; כל כלי חובה נקרא, והדוח אומר איזה עוזר קרא לו; בלי מפתח Gemini המערכת עוברת ל־Ollama |

## CI (GitHub Actions)

`.github/workflows/tests.yml` רץ בכל push:

- `sqlite`: כל הסוויטה.
- `sql-server`: אותה סוויטה מול SQL Server 2022, אותו מנוע כמו Somee.
- `docker`: `docker compose build`.

## בדיקה ידנית מול השירותים האמיתיים

1. `docker compose up -d --build`, ואז `docker compose exec web python seed_demo.py`.
2. `python -m scripts.smoke_flow http://127.0.0.1:5050`: הגשה, הערכת סוכן, החלטה.
3. `docker compose logs worker`: שורת `screened ... runtime=deepagents:gemini:...`.
4. `/health`: `"backend": "mssql"` (Somee).

## בדיקות ארכיטקטורה

- Command כותב ל-`events` לפני עדכון פרויקציה.
- Query לא קורא ל-`event_store.append`.
- אין מחרוזות נושא-טיסות בקוד המוצר (`app/`, `templates/`).
