| דרישה | איך זה אצלנו | סטטוס |
|---|---|---|

| לפחות שני סוגי משתמשים | שלושה: מועמד, מגייסת, מנהל גיוס. לכל אחד סמכות שאין לאחרים. הפירוט באפיון הפונקציונלי, בסעיף כניסה והרשאה | מולא |
| חיפוש | חיפוש משרות, וחיפוש מועמדים לפי דמיון קורות החיים למשרה | מולא |
| דף פרטים | דף משרה, ודף מועמדות עם דוח הסוכן והיסטוריית ההערכות | מולא |
| טבלה | כרטיסי משרות עם דפדוף, טבלת מועמדים, וטבלת דירוג | מולא |
| לוח משרות פתוחות ומספר נרשמים | כרטיסים, טבלה וגרף | מולא |

| סוכן בתהליך נפרד: קורא מהמסד, מחפש באינטרנט, משווה קורות חיים, ונותן ציון | תהליך `worker` נפרד מהאתר, עם שני עוזרים, חיפוש לפי משמעות, וחיפוש Tavily | מולא (הרצה אמיתית עם Gemini: ציון 83, 157 שניות) |

## איך המערכת בנויה

| דרישה | איך זה אצלנו | סטטוס |
|---|---|---|
| סדרת מסמכי אפיון | `docs/00` עד `docs/08` | מולא |
| מתכון Flask מאתר skills.sh | `flask-python` ב-`.agents/skills/flask-python`, ו-`skills-lock.json` | מולא |
| מתכון מקומי וחוק קבוע לסוכן הקוד | שני מתכונים ב-`.cursor/skills/`, וחוק ב-`.cursor/rules/sdad.mdc` | מולא |
| האתר כתוב ב-Flask | התיקייה `app/`, והאתר רץ ב-Docker | מולא |
| מסד נתונים בענן (Somee) | SQL Server בכתובת `fitscreen.mssql.somee.com`. דף `/health` מראה שהמסד מחובר. אותן בדיקות רצות גם מול SQL Server ב-GitHub | מולא |
| קורות חיים נשמרים לחיפוש לפי משמעות | Chroma והמודל all-MiniLM-L6-v2. קורות החיים מחולקים לקטעים. דירוג המועמדים משתמש בזה. בבדיקות האוטומטיות ההטמעה מזויפת | מולא |
| המסך, הכתיבה והקריאה מופרדים | המסכים ב-`views`, הכתיבה ב-`commands`, הקריאה ב-`queries` | מולא |
| בענן, וכל שינוי נשמר כאירוע | טבלת `events` ב-Somee לא נערכת ולא נמחקת. הטבלאות של המסכים נבנות ממנה. `app/replay.py` בונה אותן מחדש. היסטוריית ההערכות נקראת מהאירועים | מולא |
| שירות חיצוני דרך MCP | חיפוש האינטרנט הוא שרת Tavily. שליחת המייל היא שרת Gmail. תהליך הרקע שולח את המייל ורושם אם נשלח או נכשל | מולא לחיפוש. ל-Gmail: הקוד והבדיקות קיימים, וההתחברות נבדקה עד שגוגל מחזיר לדפדפן. שליחה אמיתית מחכה לחיבור החשבון |
| שני כלים שקוראים קורות חיים | שרת `python -m mcp_studio`. כלי אחד מוציא פרופיל, והשני בודק כמה דרישות מכוסות | מולא |
| סוכן עם תכנון, חיפוש לפי משמעות, וחיפוש באינטרנט | מנהל ושני עוזרים: אחד לקורות החיים ואחד לרשת. המודל הראשי Gemini, ו-Ollama אם הוא לא זמין | מולא |
| הקוד ב-GitHub והבדיקות רצות שם | [smerzel/AIproject](https://github.com/smerzel/AIproject). שלוש בדיקות: מסד מקומי, SQL Server, ובניית Docker | מולא |

- מסך שרק מציג מידע לא כותב לטבלאות.
- בלי מודל שפה, תהליך הרקע לא נותן ציון.
